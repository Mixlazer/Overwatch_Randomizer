# Overwatch Randomizer 2.7

[English](#english) · [Русский](#русский)

<a id="english"></a>

## English

A major cross-platform release introducing the redesigned .NET MAUI interface, Android support, deterministic counterpick recommendations, and fully local vision AI.

### Highlights

- Complete Windows and Android redesign with responsive narrow-screen layouts.
- Four focused tabs: Random, Game, Counters, and AI Chat.
- Signed Android ARM64 APK with direct camera capture for match scoreboards.
- Windows x64 Setup and a single portable EXE with bundled CPU and Vulkan runtimes.
- Fixed the desktop-shortcut permission error by creating it for the current user instead of the public desktop.
- Russian and English interfaces, including language selection before any model download.

### Counterpicks

- Select the enemy team manually or recognize it with the local vision model.
- The recognition prompt treats red rows as enemies and blue rows as teammates.
- Supports 5v5, Open 6v6, Stadium, and seven competitive ranks.
- Produces five deterministic teams with the required role composition and no repeated heroes across the recommendations.

### Game mode

- 1–10 named players with personal five-hero `1-2-2` pools.
- Collapsible player cards and a reliable dropdown for player count.
- Exact-hero purchases, role rerolls, full rerolls, and one free personal reroll per round.
- Points, `2:1` transfers, manual statistics, and local scoreboard recognition.
- **New Round** awards points and restores free rerolls.

### Local AI

- Standard model: `unsloth/Qwen3.5-0.8B-GGUF`, `Q4_K_M` weights, approximately 740 MB download.
- Advanced model: `unsloth/Qwen3.5-2B-GGUF`, `Q4_K_M` weights, approximately 1.95 GB download.
- The advanced option has a red hardware warning and is recommended only for high-end devices.
- Strict JSON Schema structured output for player statistics and enemy-team recognition.
- Local AI chat with no endpoint configuration or cloud data transfer.
- Windows: Auto/GPU Vulkan/CPU. Android ARM64: CPU.

### Screenshots

- Android opens the camera directly from the Game and Counters tabs.
- Windows always opens the system file picker.
- JPG, JPEG, PNG, HEIC, HEIF, WebP, and BMP are supported; HEIC/HEIF is converted locally on Android.

### Validation

- Windows x64 and signed Android ARM64 packages built with no errors or warnings.
- APK metadata: `versionCode 27`, `versionName 2.7`, v1/v2/v3 signatures.
- Game rules, scoring, the VLM parser contract, and deterministic counterpick checks passed.

### Release assets

- `OverwatchRandomizerSetup.exe` — recommended Windows installation.
- `OverwatchRandomizer-Portable-x64.exe` — single-file portable Windows x64 launcher.
- `OverwatchRandomizer-arm64-v8a.apk` — Android ARM64 package.

## Русский

Крупный кроссплатформенный релиз: новый интерфейс .NET MAUI, Android-версия, режим контрпиков и полностью локальный VLM.

## Главное

- Полный редизайн для Windows и Android с адаптацией под узкие экраны.
- Четыре вкладки: Рандом, Игра, Контры и ИИ-чат.
- Подписанный Android ARM64 APK с камерой для съёмки таблицы матча.
- Windows x64 Setup и один portable EXE со встроенными CPU/Vulkan runtime.
- Исправлена ошибка прав при создании ярлыка: теперь он создаётся на рабочем столе текущего пользователя, а не в публичном каталоге.
- Русский и английский интерфейс, включая выбор языка до загрузки модели.

## Контрпики

- Состав противника выбирается вручную или распознаётся локальной VLM.
- Промпт учитывает цвет таблицы: красные строки — противники, синие — союзники.
- Поддерживаются 5v5, Open 6v6 и Stadium, а также семь соревновательных рангов.
- Результат — детерминированный топ-5 составов с нужными ролями и без повторения героев между составами.

## Игра

- 1–10 игроков с именами и личными наборами из пяти героев `1-2-2`.
- Сворачиваемые карточки игроков и стабильный выбор количества через выпадающий список.
- Покупка точного героя, реролл роли, полный и бесплатный раундовый рероллы.
- Очки, переводы `2:1`, ручная статистика и заполнение статистики со скриншота.
- Кнопка «Новый раунд» начисляет очки и восстанавливает бесплатные рероллы.

## Локальный ИИ

- Обычная модель: `unsloth/Qwen3.5-0.8B-GGUF`, веса `Q4_K_M`, загрузка около 740 МБ.
- Продвинутая модель: `unsloth/Qwen3.5-2B-GGUF`, веса `Q4_K_M`, загрузка около 1,95 ГБ.
- Продвинутая модель отмечена красным предупреждением и рекомендуется только для топового железа.
- Строгий structured output через JSON Schema для статистики и состава противника.
- Локальный ИИ-чат без endpoint и облачной передачи данных.
- Windows: Auto/GPU Vulkan/CPU. Android ARM64: CPU.

## Скриншоты

- Android открывает камеру непосредственно из вкладок Игра и Контры.
- Windows всегда открывает системный проводник.
- Поддерживаются JPG, JPEG, PNG, HEIC, HEIF, WebP и BMP; HEIC/HEIF на Android преобразуются локально.

## Проверено

- Windows x64 и подписанный Android ARM64 собраны без ошибок и предупреждений.
- APK: `versionCode 27`, `versionName 2.7`, подписи v1/v2/v3.
- Пройдены проверки игровых правил, формулы очков, VLM-контракта и детерминированных контрпиков.

## Файлы релиза

- `OverwatchRandomizerSetup.exe` — рекомендуемая установка Windows.
- `OverwatchRandomizer-Portable-x64.exe` — однофайловый portable launcher для Windows x64.
- `OverwatchRandomizer-arm64-v8a.apk` — Android ARM64.
