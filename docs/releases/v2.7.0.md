# Overwatch Randomizer 2.7

Крупный кроссплатформенный релиз: новый интерфейс .NET MAUI, Android-версия, режим контрпиков и полностью локальный VLM.

## Главное

- Полный редизайн для Windows и Android с адаптацией под узкие экраны.
- Четыре вкладки: Рандом, Игра, Контры и ИИ-чат.
- Подписанный Android ARM64 APK с камерой для съёмки таблицы матча.
- Windows x64 Setup и portable-сборка с CPU/Vulkan runtime.
- Русский и английский интерфейс, включая выбор языка до загрузки модели.

## Контрпики

- Состав противника выбирается вручную или распознаётся локальной VLM.
- Промпт учитывает цвет таблицы: красные строки — противники, синие — союзники.
- Поддерживаются 5v5, Open 6v6 и Stadium, а также семь соревновательных рангов.
- Результат — детерминированный топ-5 составов с нужными ролями и без повторения героев между составами.

## Игра

- 1–10 игроков с именами и личными наборами из пяти героев `1-2-2`.
- Сворачиваемые карточки игроков и стабильный выбор количества через выпадающий список.
- Покупка точного героя, реролл роли, полный и бесплатный раундовый рероллы.
- Очки, переводы `2:1`, ручная статистика и заполнение статистики со скриншота.
- Кнопка «Новый раунд» начисляет очки и восстанавливает бесплатные рероллы.

## Локальный ИИ

- Обычная модель: `unsloth/Qwen3.5-0.8B-GGUF`, веса `Q4_K_M`, загрузка около 740 МБ.
- Продвинутая модель: `unsloth/Qwen3.5-2B-GGUF`, веса `Q4_K_M`, загрузка около 1,95 ГБ.
- Продвинутая модель отмечена красным предупреждением и рекомендуется только для топового железа.
- Строгий structured output через JSON Schema для статистики и состава противника.
- Локальный ИИ-чат без endpoint и облачной передачи данных.
- Windows: Auto/GPU Vulkan/CPU. Android ARM64: CPU.

## Скриншоты

- Android открывает камеру непосредственно из вкладок Игра и Контры.
- Windows всегда открывает системный проводник.
- Поддерживаются JPG, JPEG, PNG, HEIC, HEIF, WebP и BMP; HEIC/HEIF на Android преобразуются локально.

## Проверено

- Windows x64 и подписанный Android ARM64 собраны без ошибок и предупреждений.
- APK: `versionCode 27`, `versionName 2.7`, подписи v1/v2/v3.
- Пройдены проверки игровых правил, формулы очков, VLM-контракта и детерминированных контрпиков.
